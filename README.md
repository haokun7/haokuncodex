# Codex Cloud Workspace

Shared cloud workspace for Codex, Claude Code, and Hermes Agent.

## Toolchain

- Python 3.12
- Node.js 22
- R 4.4
- LaTeX (TeX Live)
- Stata: install separately from a licensed distribution; set `STATA_PATH`

Skills are stored in `skills/` and are intended to be shared by all three agents.
